# 지표 · 값이 없을 때 케이스 정리 (Figma 플러그인, 일회용)

LLM-Gateway 파일의 'LLM Gateway 엔드포인트 상세 페이지 - 지표 제공' 페이지에 새 섹션 **운영 지표 · 값이 없을 때 — 케이스 정리 (11/06)** 를 만든다. 기존 '운영 지표 · PRD-368' 섹션의 케이스 프레임을 복제해 아래 규칙대로 값을 바꾼다.

| 케이스 | 규칙 | 원본 |
|---|---|---|
| C0 | 불러오는 중 | M15 |
| C1 | 수집되고 값이 옴 → 다 보임 | M1 |
| C2 | 수집되지만 덜 옴 → 표본 부족 | M7 |
| C2 · 0건 | 호출 기준은 표본 부족, 요청 수 0건, 출력 처리량 `-` | M6 |
| C3 | 수집 끊김 · 서빙 중단 · 프리픽스 캐시 꺼짐 → `-` | M12 · M11 · M13 |
| C4 | 수집 안 됨 → 카드 미노출 + 이유 한 줄 | M9 |
| C5 | 불러오기 실패 | M16 |

원격 Figma MCP 에 Pretendard 가 없어 이 파일의 글자를 바꿀 수 없어서 데스크톱에서 돌리는 플러그인으로 만들었다.

## 실행

1. Figma 데스크톱에서 LLM-Gateway 파일을 연다.
2. 메뉴 › 플러그인 › 개발 › **매니페스트에서 플러그인 가져오기…** → 이 폴더의 `manifest.json`.
3. 메뉴 › 플러그인 › 개발 › **지표 · 값이 없을 때 케이스 정리 (LLM Gateway)** 를 누른다.

같은 이름의 섹션이 이미 있으면 아무것도 하지 않는다. 다시 만들려면 그 섹션을 지우고 실행한다. 되돌리려면 Cmd/Ctrl+Z.
