# 텍스트 스타일 맞추기 (Figma 플러그인)

텍스트 스타일이 붙지 않은 글자를 찾아, 크기 · 굵기 · 줄 높이가 가장 가까운 DS 텍스트 스타일로 바꿉니다.

## 불러오기 (처음 한 번)

1. Figma 데스크톱 앱에서 아무 디자인 파일을 엽니다.
2. 메뉴 › 플러그인 › 개발 › **매니페스트에서 플러그인 가져오기…** 를 고릅니다.
3. 이 폴더의 `manifest.json` 을 고릅니다.
4. 이후에는 메뉴 › 플러그인 › 개발 › **텍스트 스타일 맞추기** 로 엽니다.

Pretendard 가 이 컴퓨터에 깔려 있어야 스타일을 붙일 수 있습니다(원격 Figma MCP 로는 안 됨).

## 쓰는 법

1. 범위를 고릅니다 — 선택 영역 · 이 페이지 · 파일 전체. 레이어를 골라 두고 열면 '선택 영역'이 먼저 잡힙니다.
2. **찾기** — 스타일 없는 글자를 '글꼴 · 굵기 · 크기 · 줄 높이'가 같은 것끼리 묶어서 보여 줍니다. 아무것도 바꾸지 않습니다.
3. 묶음마다 추천 스타일이 골라져 있습니다. 드롭다운으로 바꿀 수 있고, **보기** 를 누르면 그 묶음 레이어를 캔버스에서 선택합니다.
4. 체크한 묶음만 **적용** 됩니다. 되돌리려면 Cmd+Z.

### 추천 등급

| 등급 | 뜻 | 기본 체크 |
|---|---|---|
| 정확 | 크기 · 굵기가 같음 | 켬 |
| 근접 | 크기 차이 1px 안(옵션) + 굵기 한 단계(100) 안. 예: Bold → SemiBold, 15 → 14 | 켬 |
| 먼 짝 | 그 밖. 예: 16 Regular → Heading/xs(16 SemiBold) | 끔 — 보고 고르기 |
| 짝 없음 | 후보가 없음(예: mono 글꼴인데 mono 스타일이 없음) | 끔 |

짝짓기 순서는 크기 차이 → 굵기 차이 → 줄 높이 차이입니다. mono 글꼴(Source Code Pro 등)은 mono 스타일끼리만 짝짓습니다.

### 후보 스타일

- **DS 기본**: Design system 라이브러리의 Body/sm · md · lg(regular · medium · semibold), Body/md/mono, Heading/xs · sm · md — `code.js` 의 `PRESET_STYLE_KEYS`. 라이브러리 스타일은 플러그인이 목록을 받을 수 없어서 키를 넣어 두었습니다. 다른 스타일을 더하려면 키를 추가하세요.
- **로컬**: 이 파일에 정의한 텍스트 스타일(옵션, 기본 켬).
- **다른 라이브러리**: 이 범위에서 이미 쓰는 라이브러리 스타일(옵션, 기본 끔).

### 건너뛰는 글자 (옵션으로 끌 수 있음)

- 라이브러리 컴포넌트 인스턴스 안 — 이미 DS 스타일이 붙어 있음. 이 파일에서 만든 컴포넌트의 인스턴스 안 글자는 바꿉니다.
- 이름이 `DHS` 로 시작하는 레이어 안 — 노트 · 메모 · 머리띠 같은 주석.
- 숨긴 레이어.

## 기존 '공지 게시판 · DS 텍스트 스타일 적용' 과 다른 점

`../notice-ds-typography` 는 공지 게시판(PRD-374) 파일용으로 만든 것으로, 정해 둔 '크기|굵기' 13쌍에 맞는 레이어만 화면 없이 한 번에 바꿉니다. 이 플러그인은 표에 없는 크기도 가장 가까운 스타일을 추천하고, 묶음별로 보고 고른 뒤 적용합니다. 레이어 안 일부 구간만 스타일이 없는 경우도 그 구간만 바꿉니다.
